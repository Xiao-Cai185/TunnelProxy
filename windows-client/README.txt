TunnelProxy Windows Client
============================

Version: v1.0.0
Platform: Windows 10/11 (x64)

System Requirements
--------
- Windows 10/11 (x64)
- Administrator privileges

Usage Instructions
--------
1. Right-click TunnelProxyGUI.exe and select "Run as administrator"
2. Enter Device ID (created in management platform)
3. Enter management platform address
4. Click "Sync Policy" to get configuration
5. Configure proxy server information
6. Click "Start" to begin proxy service

Features
--------
- Process-level traffic interception (based on WinDivert)
- Support SOCKS5 and HTTP proxy
- Rule matching (support wildcards)
- Real-time connection log
- Automatic policy synchronization

Notes
--------
- Must run with administrator privileges
- First run may require driver installation
- Firewall may prompt to allow network access
